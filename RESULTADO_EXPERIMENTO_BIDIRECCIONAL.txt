Archivo: Defragmenter.java
Método: posicionDelEnlaceEnRuta()
Línea: 1023-1036

ANTES:
```java
if (li.getFrom() == from && li.getTo() == to) {  // Solo dirección exacta
    return i;
}
```

DESPUÉS:
```java
// Buscar dirección directa O inversa (cores compartidos)
if ((li.getFrom() == from && li.getTo() == to) ||
    (li.getFrom() == to && li.getTo() == from)) {
    return i;
}
```
